# NetWork Stats

Simple Website used to get your ping.

## Description

This is a simple website that shows your live ping by pinging CloudFlare servers (https://cloudflare.com/cdn-cgi/trace), It also uses IpIfy to get the ip of the server and IpWho.Is to geolocate the country and city of the ip. The ping text ("Ping: ...ms") will change colour depending on your ping, starting as green at 0-80 and working its way up to red depending on what your ping is.

## Getting Started

### Executing program

* To run the program you just open the demo link (https://chocgamer27.github.io/NetWork-Stats/) or localhost the html file (index.html) and it should run automatically once the page is open.

## Help

A problem I encountered was it not working and the console showing "ERR_BLOCKED_BY_CLIENT", this error for me was due to having an adblocker (Ublock origin), this may or may not happen if you use the same or a similar adblocker, if it happens the fix is as simple as turning off the adblocker while your testing your ping then re-enabling it!
